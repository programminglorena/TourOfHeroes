### Primeiro criamos a aplicação inicial do projeto com:
ng new TourOfHeroes

A CLI do Angular instala os packages npm Angular necessários e outras dependências.

### 1: Componentes Angular

* app.component.ts => Classe do componente, escrita em TypeScript.

* app.component.html => Template do componente, escrita em HTML.

* app.component.css => Estilos CSS ou SCSS privados do componente.

### 2: Mudando o título da aplicação

1. Declare a propriedade title no arquivo app.component.ts
2. Chame esta propriedade para o template HTML com a interpolação dentro da tag h1
